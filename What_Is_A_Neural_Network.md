# What is a 25 - 20 - 10 Neural Network?

A 25 - 20 - 10 Neural Network is a small sized network compaired to larger ones. 

You have a 5 x 5 grid with 1's and 0's. 1 for ON and 0 for OFF. 
It takes the 1's and 0's and lines them up vertical. 
Each number goes into a "node" or a spot.
Each number is given a weight that decides the relevance of the number (1 or 0)
